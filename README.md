# ⚡ El Mundo Mágico | Cronología de Harry Potter y Animales Fantásticos

Bienvenido al repositorio interactivo **Wizarding Chronicles**, una experiencia web inmersiva dedicada a la cronología, personajes, películas, hechizos y criaturas del universo mágico de **Harry Potter** y **Animales Fantásticos**.

---

## 📖 Descripción del Sitio Web

Este sitio web es una guía interactiva y visual diseñada para que fanáticos y nuevos espectadores puedan explorar el universo mágico en orden cronológico y de lanzamiento. 

Incluye:
- **Línea de tiempo cronológica**: Explora los eventos desde la era de *Animales Fantásticos* (década de 1920) hasta las aventuras en *Hogwarts* con *Harry Potter* (década de 1990).
- **Tarjetas interactivas de películas y eventos**: Sinopsis, directores, fecha de estreno, personajes clave y curiosidades.
- **Filtros y buscador dinámico**: Filtra por saga (*Animales Fantásticos* o *Harry Potter*) o busca por personajes y títulos en tiempo real.
- **Efectos visuales mágicos**: Fondo con partículas animadas de estrellas y polvo luminoso en Canvas, estilo visual *Glassmorphism* (cristal esmerilado) y tipografías temáticas.
- **Efectos sonoros y Web Audio API**: Sonidos interactivos mágicos al navegar e interactuar con los elementos.

---

## 🛠️ Tecnologías Utilizadas

- **HTML5 Semántico**: Estructura accesible y organizada.
- **CSS3 Moderno**: Diseño responsivo, efectos de cristal (*Glassmorphism*), animaciones fluidas y variables CSS.
- **JavaScript (ES6+)**:
  - `data.js`: Base de datos de películas, personajes y eventos mágicos.
  - `script.js`: Manejo del DOM, filtros dinámicos, canvas de partículas interactivas y efectos de audio.

---
